Offline & Server Sync (Google Drive)

Yahan jo Drive jodoge wo saari companies ke liye default hoga (har company apna alag Drive bhi Company tab se jod sakti hai). Offline mein app normal chalta hai, internet aate hi backup apne aap ho jata hai.

Backup tabhi hota hai jab internet ho. Agar app band thi ya internet nahi tha, to app khulte hi / internet aate hi chhuta hua backup ho jata hai.

Google Drive kaise jodein (5 minute, ek baar)
  1. Jis Google account ke Drive mein backup chahiye (aapka ya kisi aur ka) us account se login karo.
  2. Neeche "Script copy karo" dabao (key apne aap ban jayegi).
  3. script.google.com kholo → New project → purana code hata kar paste karo → Save.
  4. Deploy → New deployment → Web app → Execute as: Me → Who has access: Anyone → Deploy (permission Allow karo).
  5. Jo "Web app URL" mile use neeche paste karo → "Save & Test". Backup us account ke Drive ke "AJ_Billing_Server_Backup" folder mein banega.

Kuch companies ka naya data Drive par kisi aur device se aaya hai. Kya karna hai?

Drive par har company ka latest backup + pichla version + roz ka snapshot (last 10 din) rehta hai. Company delete karne se Drive ka backup delete nahi hota.

Auto Backup File (Offline)

Bina internet ke bhi: aapke chune hue time (1 minute se 1 din) par jab data badla ho, backup apne aap ban jata hai aur is device mein save rehta hai. Chaho to file folder ya Downloads mein bhi ban sakti hai. Ye tab chalta hai jab app khula ho.
